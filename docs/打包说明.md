## 2. 怎么打

```bash
# 0. 依赖（开发机）
python3 -m pip install -r requirements-p4.txt
npm install

# 1. 抓取便携 CPython + vendor pypdf（写入 build/，不进 Git）
python3 scripts/prepare_pack.py --platform linux-x64   # 或 win-x64
# 等价拆步：
#   python3 scripts/fetch_python_runtime.py --platform win-x64 --dest build/runtime
#   python3 scripts/prepare_pack.py --skip-runtime && 仍会 vendor pypdf

# 2. 打包
npm run pack:linux          # dir + zip
npm run pack:win            # 必须在 Windows：nsis + zip + portable
npm run pack:linux -- --dir-only
```

`electron-builder.yml` 已写明 Windows 目标。`forceCodeSigning: false`、`win.signAndEditExecutable: false`：**产物未签名**，SmartScreen 会提示。

## 3. 包内布局（extraResources）

解压免安装包或打开 `linux-unpacked/`：

```
resources/
  app.asar                 Electron 壳（E1）
  assets/templates/        37 份冻结模板（只读约定）
  assets/templates-backup/
  assets/spec/             字典 / 规则 / 目录
  assets/engine/           确定性引擎 + shell_bridge
  lib/                     Python 库（含打包时的 lib/vendor/pypdf）
  tools/                   体检与 P0–P7 回归
  examples/
  docs/使用手册.md
  python/                  便携 CPython（抓取成功时）
  optional/dsh-yanshou-docs/   组合包源码，不含 dsh 运行时
  pack-manifest.json
```

主进程用 `src/runtime.js` 解析：打包后根 = `process.resourcesPath`，Python 优先 `resources/python/python.exe`（Win）或 `resources/python/bin/python3`（Linux），工作目录写到用户数据目录，**绝不写模板**。

引擎几乎是标准库；唯一第三方 **pypdf** 在打包时 `pip install -t build/vendor`。不再内嵌 lxml（P0 已改为 xml.etree）。

## 4. 干净 Windows 不装系统 Python / Node

| 需求 | 处理 |
|---|---|
| 运行桌面壳 | Electron 可执行文件自带 Chromium/Node |
| 跑引擎 | 捆绑 `python/`（`scripts/fetch_python_runtime.py` 拉 python.org embed-amd64） |
| PDF 合并 | `lib/vendor/pypdf` + `PYTHONPATH` |
| 开发 `npm run dev` | 仍要本机 Node ≥ 22.14 与 Python 3.12 |

若构建时没能下载 embeddable Python，包会回退到系统 `python`/`python3`，并在 `pack-manifest.json` 里 `pythonRuntime: false`。Windows 交付前必须确认清单为 `true`。

## 5. 可选 AI / dsh（基础包默认不含运行时）

dsh 运行时约 **420MB**，打进基础包会爆炸。基础包只带 `optional/dsh-yanshou-docs` **源码**。

加装（开发机 / 内网机，**不要把 Key 写入 Git 或 patch**）：

```bash
pip install "deepseek-harness-sdk==0.1.5rc1"
export DSH_HOME=/path/to/dsh-home          # 必须非空，禁止回退 ~/.dsh
mkdir -p "$DSH_HOME"
export DEEPSEEK_API_KEY=...                # 仅环境变量
dsh --profile yanshou --from-default-profile sdk
cd optional/dsh-yanshou-docs || cd packages/dsh-yanshou-docs
pnpm install && pnpm build && pnpm pack
dsh plugin --profile yanshou add ./dsh-yanshou-docs-0.2.0.tgz
```

无 dsh、无 Key、断网：AI 入口置灰，其余功能不受影响（P6 已实现；P7 用 `run_p7_regression.py` 与 `YANSHOU_AI_OFFLINE=1` 复证）。

## 6. 从安装布局跑 P0–P6 回归

```bash
# Linux 烟测包
export YANSHOU_ROOT=$PWD/dist/linux-unpacked/resources
export YANSHOU_WORK=/tmp/yanshou-work
export PYTHONPATH=$YANSHOU_ROOT/assets/engine:$YANSHOU_ROOT:$YANSHOU_ROOT/lib/vendor
# 有捆绑解释器则优先：
PY=$YANSHOU_ROOT/python/bin/python3
[ -x "$PY" ] || PY=python3
"$PY" "$YANSHOU_ROOT/tools/run_regression.py"
"$PY" "$YANSHOU_ROOT/tools/run_p6_regression.py" --skip-prior
"$PY" "$YANSHOU_ROOT/tools/run_p7_regression.py" --skip-prior --pack "$YANSHOU_ROOT"
```

Windows zip 内将 `python\python.exe` 换成上述 `PY`，`YANSHOU_ROOT` 指向 `resources\`。

源码树（未打包）照旧：

```bash
python tools/run_p7_regression.py --skip-pack
npm run p7:smoke
```

### Windows 便携包「创建工程」与 `_common`

打包后的 Windows embeddable CPython 带 `python._pth`，**不会**把 `shell_bridge.py` 所在目录放进 `sys.path`，而且会忽略环境变量 `PYTHONPATH`。若只把安装根 + `lib/vendor` 写进 `PYTHONPATH`（旧 `pythonEnv`），就会在便携/exe 里建档时报：

```
ModuleNotFoundError: No module named '_common'
```

路径形如 `...\resources\assets\engine\shell_bridge.py`（Electron 拉起捆绑 Python）。

修复不依赖 `._pth` 单独生效：

1. 每个 `assets/engine/*.py` 在 `from _common import ...` **之前**把 `Path(__file__).resolve().parent`（以及安装根）插入 `sys.path`。
2. `src/runtime.js` 的 `pythonEnv` 把 `assets/engine` 放进 `PYTHONPATH` 最前（给非 embed 解释器）。
3. 抓取 embeddable 时 `python*._pth` 仍会写上 `..\assets\engine` 等相对路径，但脚本侧插入才是主修复。

本仓库 Linux 即可复证（不必打 Windows 包）。`-P` / `PYTHONSAFEPATH=1` 模拟「脚本目录不在 sys.path」；`PYTHONPATH` 故意只给根 + vendor（旧 `pythonEnv`）。`-I` 再忽略 `PYTHONPATH`，贴近 `python._pth` isolated：

```bash
# 旧 pythonEnv：不含 assets/engine；-P 不把脚本目录放入 sys.path
PYTHONSAFEPATH=1 PYTHONPATH="$PWD:$PWD/lib/vendor" python3 -P \
  assets/engine/shell_bridge.py --action create \
  --dir /tmp/yz-embed-create \
  --fields '{"projectName":"t","ownerUnit":"a","constructionUnit":"b"}' --json

# 更严：-I 忽略 PYTHONPATH（等价 embeddable ._pth）
python3 -I assets/engine/shell_bridge.py --action open \
  --project /tmp/yz-embed-create/project.json --json
```

不应再出现 `No module named '_common'`。同一闸门在 `python tools/run_p7_regression.py --skip-pack`。
