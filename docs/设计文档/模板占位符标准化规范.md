## 二、占位符语法规范

统一采用双花括号，一种标记走到底。

### 2.1 单值
```
{{字段key}}                    例：工程名称：{{projectName}}
{{字段key|默认文本}}            例：{{supervisionUnit|本项目无监理}}
```

### 2.2 日期 —— 一律不自动填

**所有日期不注入占位符、不参与填充引擎**，模板里的日期留白（`年　　月　　日`、`XX年XX月XX日`、`日　期：`）**原样保留**，人工在编辑区手写。

- 原 12 个日期字段（开工/完工/创建/文档/签署/日志/评审/移交/初验/验收/试运行开始/数据治理）已从字段字典移入 `disabledFields`，程序不渲染这些表单项
- 扫描时此类位置记为 `@manualDate`，类型标「手填·日期」，UI 给 ✍️ 提示
- **不计入待填点、不参与残留校验**，导出时不做任何替换
- 编辑区可自行手打；后续挂日期选择器属编辑辅助，不算自动填充

### 2.3 自动编号（见第八节）
```
{{docNo}}                       → YY123-KGBSB-01
```

### 2.4 表格动态行（8 张子表）—— 程序端自动识别（工头 2026-09-12 定稿）

子表**不在模板里插任何标记**，由程序端按**表头列名自动识别**并接管数据行：

| 契约 | 内容 |
|---|---|
| `字段字典.json` → `tablePolicy` | `enabled: true` / `mode: "program-side"` / 匹配依据 = 表头列名序列 |
| `字段字典.json` → `tables` | 每张子表的**列定义**（列名与顺序，取自模板实际表头） |

**识别与填充规则：** 程序读到列名序列与 `tables[].columns` 匹配的静态表格即接管 —— 按 columns 顺序填充数据行，**行数不足则克隆、多余则删除**；模板侧保持静态表格，**禁止出现 `{{#rows:}}` / `{{/rows}}`**。

> 取消区块标记的理由：模板表格普遍含合并单元格、总计行、小计行、会签栏，插入区块标记极易破坏结构。改由程序端按表头识别更稳。

### 2.5 条件块（后期）
`{{#if hasSupervision}}...{{/if}}` —— 用于"有/无监理单位"这类整段显隐。

### 2.6 图片
`{{image:topologyMap}}` —— 保留原尺寸与环绕方式替换。

### 2.7 命名硬规则
key 一律小写驼峰；禁用中文、空格、连字符；字典发布后**只增不改名**（改名要全量重扫模板）。

## 六、技术实现要点（实战踩坑记录）

### 坑 1：Word 会把 `{{projectName}}` 拆成多个 run
必须**跨 run 替换**：取段落内所有 run 文本拼成完整字符串并记录每个 run 的偏移 → 定位要替换的偏移区间 → 结果写回覆盖的起始 run、清空跨越的其余 run 文本 → **未触及的 run 与其 rPr 保持不变（只动文本不动格式）**。

> 本次注入即用此策略（脚本 `splice()`），实测替换后原加粗、下划线等格式全部保留。

### 坑 2：表格行数不固定
不能用"填空"思维。必须**行克隆**：读首个数据行作为模板行，按数据条数 deepcopy XML 节点插入，再逐行替换。**合并单元格（`vMerge`）要特殊处理**，否则错行。

### 坑 3：日期位置必须原样跳过
既然日期一律不自动填，`年　　月　　日` 这类全角空格排版**整段保持原样**。注入脚本按映射表 `目标字段 == @manualDate` 明确跳过这些位置 —— 既不能替换，也不能顺手清理空格，否则破排版。
注意：部分单元格是「正文 + 日期」混排（如"本项目于　年　月　日通过初步验收…"），**只处理正文里的字段，日期部分留给人工**。

### 坑 4：正则量词必须用 `{2,}`，不能写 `{2}`
中文占位写法有 `XX` / `XXX` / `XXXX` 多种长度。`[×X]{2}项目` 只能匹配恰好 2 个 X，遇到 `XXX项目` 直接失配、静默漏注入。**一律用 `[×X]{2,}`**。

### 坑 5：同段落内多条替换规则的区间不能重叠
「段首空白 + 项目」与紧跟的「（方案审核文号：　　）」相邻时，若拆成两条规则，前者的区间会盖住后者起点，去重逻辑丢弃后者 → 字段漏注入且不报错。**相邻位置必须合并成一条正则。**

### 坑 6：模板内的「提示文字」不是占位符
`简述监理实施过程，对项目…提出结论性意见。监理单位签章：` 这类整句是**填表说明**，后面跟的是签章位。自动识别会误判成 `supervisionUnit` 字段。**判断标准：空格/下划线紧邻签章、签字、盖章字样时，属人工区，不注入。**

### 坑 7：改同一文件禁止并行编辑
批量维护脚本时，同一轮并行提交多个编辑会因读-改-写竞态互相覆盖，只有最后一个生效。**改同一文件必须串行提交，改完复核文件内容。**

### 坑 8：注入后必须比对 docx 部件
docx 重新保存会剥离 zip 目录条目（`word/`、`_rels/` 等以 `/` 结尾的项），属正常现象；但必须确认**实际文件部件无缺失、图片等二进制逐字节一致**，否则会悄悄丢资源。

### 坑 9：字典「启用字段」与模板「实际使用 key」必须严格相等
字典里留着模板没用的字段，程序会渲染出永远填不进去的空表单项；模板里出现字典没有的 key，填充时会静默漏替。**每次改字典或改模板后用 `field_usage_diff.py` 对一次账，两边数量与集合必须完全一致。**

## 七、三条技术路线对比

| 路线 | 语法 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| **A. 文本占位符** | `{{key}}` | 通用、任何 docx 引擎都能实现、改造简单、模板照常能用 Word 打开 | 需处理 run 拆分 | ✅ **主推（已落地）** |
| B. 邮件合并域 | `MERGEFIELD` | Word 原生、可视化 | 需配数据源，genoffice 支持弱 | ❌ 不推荐 |
| C. 内容控件 | `SDT` + tag | 可锁定、按 tag 精确定位 | 依赖 Word 生态 | ⚠️ 局部用（签字栏等） |
| D. 自定义 XML 部件 | `customXml` | 数据与文档彻底分离 | 实现复杂 | 🔶 后期可选 |

**推荐组合：A 为主 + C 局部增强。**

## 八、文档编号规则

**业务目的：** 同一张表可能不止一份（施工日志几十份、开箱记录多份），需要用编号区分。

**规则：**
```
有合同编号：  {合同编号}-{表名缩写}-{流水号}     例：YY123-KGBSB-01
无合同编号：  {表名缩写}-{流水号}                例：KGBSB-01
```

- 合同编号直接取项目合同编号（如 `YY123`）
- **表名缩写 = 表名每个汉字的拼音声母取大写**（开工报审表 → `KGBSB`）；括号内补充说明不参与
- 缩写由软件自动生成，**人工可覆盖**；与旧表种码（`KGSQD`/`A25`）无关，后者已废弃
- **流水号在单个目录项内独立续排**，每个目录项各自从 01 起
- 流水号默认 **2 位**；施工日志、周报、月报、试运行记录配 3 位
- 全量缩写见 `规范/表名缩写字典.csv`（56 项）

**适用范围：只有模板内带「文档编号」标签的文档才编号，共 9 项：**

| 分册 | 目录项 | 表名缩写 | 位数 |
|---|---|---|---|
| 二 | 1.开工报审表 | `KGBSB` | 2 |
| 二 | 3.施工组织方案报审表 | `SGZZFABSB` | 2 |
| 二 | 7.设备开箱验收记录 | `SBKXYSJL` | 2 |
| 二 | 8.设备安装调试记录表 | `SBAZDSJLB` | 2 |
| 二 | 10.施工日志 | `SGRZ` | 3 |
| 二 | 11.项目周报 | `XMZB` | 3 |
| 二 | 12.项目月报 | `XMYB` | 3 |
| 五 | 1.试运行申请表 | `SYXSQB` | 2 |
| 五 | 6.试运行记录表 | `SYXJLB` | 3 |

**分配与回收：**

| 场景 | 行为 |
|---|---|
| 首次生成/保存 | 取**该目录项内**最小未占用号，**永久绑定**该文档 |
| 删除某份 | 编号释放回**该目录项**的编号池 |
| 从回收站恢复 | **取回原编号**，不重新分配 |
| 同目录内删除后 | 后续编号**不重排**（删掉 02，03 仍是 03） |

> 为什么不重排：已打印的纸质件编号必须和电子件永远一致。按列表顺序实时重排的话，中途删一份会让后面编号整体前移，发出去的纸质件当场对不上号。

**实现落点：** `目录项ID → 已用编号集合`；分配 = 取最小可用号，释放 = 移除，恢复 = 按文档ID取回原号。

**软件侧配套：**
- **唯一主键用文档 ID**，编号只作展示与打印，不能做索引
- 纸质件靠表名区分，归档按表名分堆
- **导出文件名带表名**：`YY123-KGBSB-01_开工报审表.docx`
- 编辑区顶部显示文档编号，**只读**
