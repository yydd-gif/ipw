# 占位符速查表（手动标注用）

> 字典真源：`规范/字段字典.json` · 版本 **v2.3** · 2026-09-12
> 规律：`{{英文key}}` → 填充时替换为字典里该 key 对应的值。**key 必须与下表完全一致（区分大小写）**。

---

## 一、语法三种（模板里只会出现这些）

| 用途 | 写法 | 说明 |
|---|---|---|
| 填字段 | `{{key}}` | 最常用，如 `工程名称：{{projectName}}` |
| 自动编号 | `{{docNo}}` | 系统按规则生成，不从字典取值 |
| 日期 | **不写占位符** | 全部留白人工手写（见第四节） |

> **动态表格行已取消模板标注** —— 工头 2026-09-12 定：子表由**程序端按表头列名自动识别**，模板里**不写** `{{#rows:...}}` / `{{/rows}}`，保持静态表格即可（见第三节）。

## 四、不要写占位符的位置（设计上就留空）

| 类型 | 为什么 | 涉及 |
|---|---|---|
| **所有日期** | 工头定：日期一律不自动填充，人工手写 | 25 处 `年　月　日`、`日　期：`、`签字日期` 等 |
| **意见栏 / 签章栏** | 是提示文字 + 盖章位，不是可填字段 | 七7 签署栏、五9 意见栏、二5 建设单位意见栏、七3 承诺期段 |
| **其它情况说明** | 工头 2026-09-12 定：不补占位符 | 二10 施工日志 R6 |
| **质量安全检查** | 模板内已写死固定文案 | 二10 施工日志 R5 |
| **实施人员 / 监理人员 / 备忘记录** | 现场手填 | 二8 设备安装调试记录表 |
| **专家姓名 / 电话 / 意见 / 建议 / 组长 / 成员** | 专家现场手写手签 | 七9、七10 |
| **动态表格数据行** | 行数不定，程序端按表头识别 | 8 张子表（见第三节） |
| **系统自动生成** | 目录、隔页由程序生成 | 六2 目录、八3 隔页 |
| **上传附件区** | 转附件上传通道 | 六5 培训记录表、六10 设备移交表 |
| **固定文案** | 正文已写死，无需填写 | 六8 质保期承诺书 |
| **自然语言描述** | 原因/问题内容无法预先枚举 | `由于XX等客观原因，还存在XX等问题` |
