本文件是**壳（左树 / 右键 / Ribbon）的权威口径**。与 ADR-21 冲突时以 ADR 的收录规则为准，交互细节以本备注为准。

## 收录与状态点

- **真源**只有字典「收录」列 → `inclusion`。禁止从 `软件目录.docx` 的「重要 / 普通 / 一般」推导（该文件没有「必须」字段）。
- **可选未创建** = **灰点** + 无实例。**不是缺项**，校验 / 导出不得因此硬阻断。
- **必选未创建** = **红点**。
- 已有实例：沿用现有灰 / 蓝 / 绿 / 红填充点。打印是独立「印」角标，不是第五色。

## 左树点击

- 目录项行（table-kind，尚未创建实例）**只选中该行，不打开右侧编辑/预览**。
- **只有点击已有实例**才打开右侧正文（GenOffice 嵌入优先，E1 回退）。
- 未创建时点实例入口不存在；误走打开路径则 toast，不切右栏。

## 目录项行右键菜单

三项，文案固定：

1. **新建表格** — 为该目录项创建一份实例并分配编号（可选默认 0 份，由此追加）。
2. **打开** — 打开已有实例进入右侧编辑。无实例 → toast「尚未创建实例，请先「新建表格」」，不打开右栏。
3. **删除…** — 把该实例送回收站。**编号不重排**（删 02，03 仍是 03）。无实例 → toast「没有可删除的实例」。

## Ribbon

- 一键成册按钮文案改为 **「生成必选」**。
- 行为：`docgen --item all` = **只生成必选**。可选默认 0 份；误把可选打进成册 = 失败。
