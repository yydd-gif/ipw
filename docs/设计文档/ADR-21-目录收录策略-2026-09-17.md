## 决策

验收资料**不要求目录每一项都有实例**。可选表默认 **0 份**；用户在目录行右键「新建表格」才追加一份。一键成册 / Ribbon「生成必选」/ `docgen --item all` **只生成必选（收录=必选）**，永不批量生成可选。

## 规则

1. **真源**：`表名缩写字典.csv` 的「收录」列（`必选` / `可选`）。程序字段名 `inclusion` = `required` | `optional`，写入 `_catalogSnapshot.items[]`。
2. **禁止**从 `软件目录.docx` 的「重要 / 普通 / 一般」推导必选。该文件**没有「必须」字段**；重要度只用于展示。
3. **「生成必选」 / `--item all`** = 必选 only。显式 `--item 二-01` 或壳「新建表格」才创建可选实例。
4. **新建工程不预生成**可选（也不预生成必选；必选等用户点「生成必选」或右键新建）。
5. **编号不变**：删 02 留 03，目录项内不重排。删除实例不重编号。
6. **空可选行**：无文件；未创建 = **灰点**，不是缺项。校验 / 导出不得因此硬阻断。
7. **空必选行**：未创建 = **红点**（警告，不把整册校验打成阻断，除非另有残留等 block 项）。
8. **已有实例**：点击实例打开右侧编辑器（GenOffice 嵌入 / E1 回退）。点击未创建的目录项行**不打开右栏**。

## 首刀名单（2026-09-17）

- 全部**上传项** → **可选**
- **二-01～05 显式可选**（虽有模板）：开工报审表、项目经理授权书、施工组织方案报审表、施工组织方案、工程开工令
- **其余有模板的目录项 → 必选**

合计：**32 必选 / 24 可选**（37 有模板 − 5 显式可选模板 = 32；19 上传 + 5 = 24）。后续改收录只改字典「收录」列，不改引擎过滤逻辑。

## 壳交互（筑业云对齐）

详见 `界面交互备注-ADR21-左树右键-2026-09-17.md`。摘要：

1. Ribbon「生成必选」= 必选；可选未创建显示灰点 / 无实例（不是缺项）；必选未创建红点
2. 目录行右键「新建表格 / 打开 / 删除…」→ 新建调编号引擎创建 docx + 编号；打开无实例 → toast；删除不重排编号
3. 点击已有实例 → 右侧正文编辑（嵌入优先，E1 回退）；未创建的 table-kind 单击不打开右栏

## 验收（Black Widow DoD）

① `docgen --item all` / 「生成必选」= 必选 only；可选默认 0 文件  
② 可选未创建 = 灰点，不当作缺项（verify / export 不硬阻断）  
③ 只有必选未创建 = 红点  
④ 右键「新建表格」创建可选实例 + 编号  
⑤ 误把可选打进成册 = **FAIL**  
编号：删 02 留 03 不变。

## 不做

- 不宣称画板 2 占位符四态完成
- 不改 `assets/templates`
- 不取消 E1 回退路径
