## 决策

验收资料**不要求目录每一项都有实例**。可选表默认 **0 份**；用户在目录行右键「新建表格」才追加一份。一键成册 / `docgen --item all` **只生成必选（收录=必选）**，永不批量生成可选。

## 规则

1. **真源**：`表名缩写字典.csv` 增加「收录」列（`必选` / `可选`）。程序字段名 `inclusion` = `required` | `optional`，写入 `_catalogSnapshot.items[]`。
2. **一键成册 / `--item all`** = 必选 only。显式 `--item 二-10` 或壳「新建表格」才创建可选实例。
3. **新建工程不预生成**可选（也不预生成必选；必选等用户点成册或右键新建）。
4. **编号不变**：删 02 留 03，目录项内不重排。
5. **空可选行**：无文件；沿用现有状态点，未创建 = **灰点**。不重做四态画板。
6. **已有实例**：点击实例打开右侧编辑器（GenOffice 嵌入 / E1 回退）。

## 首刀名单（2026-09-17）

- 全部**上传项** → 可选
- 有模板的目录项 **默认可选**
- **例外必选（二-01～05）**：开工报审表、项目经理授权书、施工组织方案报审表、施工组织方案、工程开工令

后续改收录只改字典「收录」列，不改引擎过滤逻辑。

## 壳交互（筑业云对齐）

1. 一键成册 = 必选；可选显示尚未创建（灰点 / 无实例）
2. 目录行右键「新建表格」→ 调编号引擎创建 docx + 编号
3. 点击已有实例 → 右侧正文编辑（嵌入优先，E1 回退）

## 不做

- 不宣称画板 2 占位符四态完成
- 不改 `assets/templates`
- 不取消 E1 回退路径
