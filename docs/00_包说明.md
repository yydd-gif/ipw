## 怎么跑起来

```bash
# 1. 定位模板里所有位置（段N / 表M行R列C）→ 导出 .workbuddy/tmp/actual_locate.json
python 03_工具脚本/locate_docx.py

# 2. 映射表 × 模板实况 全量对账（位置命中 / 字段不一致 / 覆盖缺口 / 人读残留 / 字段全集 / run 完整性）
python 03_工具脚本/diff_mapping.py

# 3. 从模板实况重建映射表（会先自动备份到 _历史版本/；加 --dry-run 只看不写）
python 03_工具脚本/gen_mapping_from_templates.py

# 4. 校验模板原始备份（两段体检：A 副本完整性 + B 源↔备份同步性；有漂移 exit 1）
python 03_工具脚本/backup_templates.py --verify-only
python 03_工具脚本/backup_templates.py --verify-only --brief   # 只出一行结论
#    --prune 额外清理源已改名/删除的陈旧副本

# 5. 填充引擎试跑   ⚠ 当前会崩：BASE 路径算错一级 + 无 lxml，修法见 模板资产核查报告.md §8.3
python 02_引擎源码/fill_engine.py --demo

# 6. 排版体检（段前分页 / 页眉页脚 / 页码域 / 页边距 / 字体 / 空白页）
python 03_工具脚本/audit_typography.py

# 7. 排版修复（删除真启用的段前分页）—— 本包当前目标 0 处，跑起来只会报「跳过」
python 03_工具脚本/fix_typography.py --dry-run

# 8. AI 组合包构建
cd 04_AI组合包/dsh-yanshou-docs && pnpm install && pnpm run build && pnpm pack
```

> ⚠ **`w:pageBreakBefore` 是 on/off 元素，必须读 `w:val`** —— 本包 199 处全是 `w:val="0"`（**显式关闭**），
> 真启用 **0 处**。体检脚本初版没读 val，曾误报「6 份模板段前分页失控」，**已撤回**（详见 `模板资产核查报告.md` §9.0 / CR-007 §7.2）。

> ⚠ 第 3 步会**覆盖** `01_设计文档/模板字段映射表.csv`。脚本已做幂等（重跑结果一致），但重跑前仍建议先确认 `_历史版本/` 里有备份。

> ⚠ `03_工具脚本/gen_field_mapping.py` 是**旧版**生成器（扫原始模板、不校准位置、不产出「来源」列）。**重跑它会打回原形**。建议废弃，改用 `gen_mapping_from_templates.py`。

## 约定（红线）

1. **不碰 `07_模板资产/` 下任何 docx**（37 份 + 171 占位符是冻结资产）；模板标注由工头手动完成，AI 只维护字典 / 规则 / 映射等辅助文件。
2. **不动模板原始备份**（`00_模板原始备份/` 只读，仅用于回溯与 diff）。
3. 引擎只读模板，输出到工程目录，**永不回写**。
4. 缺值**保留 `{{key}}` 原样**，宁可导出报错不做半成品。
5. docx 一律**部件级操作**（zip 读入 → 改 XML → 原样写回），**不用 python-docx 重排**。
6. **占位符替换必须在「同段落内跨 run 合并」后再落笔**，不得逐 `<w:t>` 替换 —— 实测 6 份模板 / 14 处占位符被 Word 拆散在多个 run，逐 run 替换会**静默漏填**（见 `模板资产核查报告.md` §8.2 / E-7）。
7. 契约冻结后改动走 **`01_设计文档/变更记录.md`**。
8. **不 fork dsh、不改 upstream 源码**；插件安装只用 tarball。
9. **编号在目录项内不重排**。
10. **日期一律不自动填**（12 个日期字段停用，`datePolicy.enabled=false`）。
11. 子表**不在模板侧标注**，由程序按表头列名识别（`tablePolicy.mode=program-side`）。
12. **包外 `E:\项目资料\模版\` / `模版.rar` / `模版_docs.zip` 是本项目唯一一份"注入前原始态"，勿动勿删勿整理**（不属于本资料包，仅作溯源）。
