# 验收资料编辑软件 · 使用手册（P7）

给资料员 / 项目经理的短手册。开发与打包说明见 [`打包说明.md`](打包说明.md)。

---

## 1. 这是什么

建一个工程 = 建一个文件夹。新建或打开后，**所有目录项都是 0 份**（含过去所谓必填的 32 项）。需要哪张表，在左侧目录树右键 **「新建表格」**（有模板）或 **「上传」**（无模板，自选文件挂入）。打完印后可导出整册 PDF。

**资料专用编辑器，不是完整 Word。** 编辑内核优先嵌入 GenOffice 源码（右侧「正文」改正文/表格，保存到**工程副本**）。模板只读。不可用时回退 **E1：表单 + 只读预览 + 子表网格**。

---

## 2. 安装与打开（Windows）

发行物二选一（均不要求电脑预装 Python 或 Node）：

| 形态 | 文件名示例 | 怎么用 |
|---|---|---|
| **安装包** | `yanshou-docs-0.7.x-win-x64-setup.exe` | 双击安装，开始菜单打开「验收资料编辑软件」 |
| **免安装包** | `yanshou-docs-0.7.x-win-x64.zip` 或 `*-portable.exe` | 解压后运行可执行文件；整个目录可拷到 U 盘 |

首次打开若被 SmartScreen 拦截：发行包**未签名**，选「仍要运行」。不要把 `DEEPSEEK_API_KEY` 写进任何文件。

Linux 烟测包是 `yanshou-docs-*-linux-x64.zip`（本仓库在 Linux CI / 开发机打包）。日常交付以 Windows 为主。

---

## 3. 日常步骤

1. **新建工程**：填工程名称、建设/施工单位（必填），选一个空文件夹。打开后左侧 8 分册 56 项都在，**文件数为 0**。
2. **填项目信息**：右侧 39 个字段只填一次；改项目级字段会问「仅本份 / 同步全册 / 撤销」。日期**不自动填**。
3. **按需建表**：
   - 有模板的行：右键 **新建表格** → 从模板生成一份并编号。
   - 无模板的行：右键 **上传** → 选择要挂入的文件（不是套模板、不是空白占位）。
   - 没有「一键铺表」按钮。`docgen --item all` 也不是产品路径。
4. **空表状态**：未建 = **灰点、无文件**（不是缺项，也不是校验失败）。单击空行**不会**打开编辑器、也不会自动建文件。右键 **打开** 在零实例时只提示；**删除**只作用于已有实例（删掉中间号，后面的号不重排）。
5. **打印标记 → 导出 PDF**：导出写入工程目录 `_导出/`。某张表没建**不是**校验失败。

工程文件夹拷走就是整套资料，不依赖本软件也能用 Word 打开 docx。

## 4. 模板体检

菜单功能区 **「模板体检」**：对照冻结备份检查 37 份模板是否齐全、占位符是否仍是 171 处、模板只读保护是否开启。

- 通过 / 警告即可用。已知 2 份 SHA 漂移（Word 另存 / 删了一个 ★）是**故意 fail-loud**，内容零丢失，见仓库 README。
- 命令行等价：`python tools/run_health.py`（开发机或免安装包 `resources/` 内）。

**不要**用 Word 另存 `assets/templates/` 里的文件。

---

## 5. 离线与 AI

**拔网线后**：新建/打开工程、填写、按需建表、子表、周报/月报、导出 PDF **全部可用**。

AI（起草 / 润色 / 扩写 / 智能填表 / 查错）在无网或没有 `DEEPSEEK_API_KEY` 时**全部置灰**，不会编造答案。周报/月报走规则引擎，不需要模型。

基础安装包**不含**约 420MB 的 dsh 运行时。要加装 AI 后端见 [`打包说明.md`](打包说明.md)「可选 AI / dsh」。

---

## 6. 子表与半自动同步

- 「子表」页 8 张网格，保存时按表头克隆行，不改模板。
- 改已生成文档里的项目级字段：选「仅本份」只写当前文档覆盖，不改档案、不碰其他文档。

---

## 7. 回归（给实施 / 验收）

从源码仓库：

```bash
python tools/run_p7_regression.py
python tools/run_regression.py          # P0：37 份 / 171 处 / 0 残留
python tools/run_p6_regression.py --skip-prior
```

从已解压的安装布局（`resources/` 为 extraResources 根）：

```bash
export YANSHOU_ROOT=/path/to/resources
export YANSHOU_WORK=/tmp/yanshou-work
# Windows 免安装包可直接用捆绑的 python.exe
python tools/run_regression.py
python tools/run_health.py
```

---

## 8. 红线（请勿破）

1. 不要改安装目录里的模板 docx。
2. 不要把 API Key 写进工程文件夹或配置文件。
3. 缺值会留下 `{{key}}`，请在打印前用体检/校验扫一遍。
